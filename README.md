🖐️ AirHands: AI Gesture Desktop & Motion Gaming

AirHands is a cutting-edge, browser-based gesture-controlled virtual desktop ecosystem powered by advanced computer vision and artificial intelligence. Built entirely using web technologies, AirHands transforms any standard computer webcam into a touchless, interactive control surface with real-time 3D hand tracking—eliminating the need for specialized motion sensors, VR controllers, or physical peripherals.

📖 Description

By running Google's MediaPipe neural network directly inside your web browser, AirHands tracks up to 21 distinct 3D landmarks per hand at up to 60 frames per second. The application converts hand movements into fluid digital inputs using linear interpolation algorithms that eliminate jitter and provide point-and-click accuracy. Users can navigate virtual cursors across their desktop simply by moving their index fingers, while quick pinch gestures between the thumb and index finger enable clicking, window dragging, and interactive drawing.

Designed for touchless interaction, gaming, and creative expression, AirHands comes equipped with a suite of motion-driven applications:

✌️ Dual-Hand Neural Engine: Independent tracking for two hands simultaneously (Hand 1 and Hand 2), allowing for single-player gesture control or cooperative two-player local interaction.

🎮 Integrated Motion Games: Includes a fast-paced Space Target Shooter where players pop targets using pinches, and a high-speed Dual-Paddle Brick Breaker where each hand independently controls a paddle to keep the ball in play.

🎨 Pro Air Whiteboard: A responsive digital canvas equipped with fine pens, markers, glowing highlighters, erasers, stroke size sliders, color palettes, and single-click PNG canvas export.

🖥️ Immersive Workspace: Clean, glassmorphic virtual desktop interface featuring expandable window containers, customizable tracking sensitivity sliders, real-time FPS counters, and synthesized Web Audio sound effects.
